A Node 22 program (standard library only) that writes one letter — `K`, for
"knackered" — to `$MAKEFUN_OUTPUT_DIR/entry.txt`, for make.fun's "One Letter
for Your Day" bounty. The entry is exactly one character, the first letter of
the word that describes the day; the judge compares letters two at a time and
picks the one whose hidden word feels more vivid, funnier or truer.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two consecutive runs produce byte-identical output (same SHA-256). No network,
no `Date.now`, no `Math.random`.
